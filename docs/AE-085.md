# AE-085: Seeded Random Allocation Strategy

## Overview

Implemented the `RANDOM` allocation strategy for distributing eligible answer scripts across selected teaching assistants with deterministic seed-based reproducibility.

## Implemented

- Added seeded random allocation through `AllocationService`.
- Uses a seeded pseudo-random generator with Fisher-Yates shuffling.
- The same input and seed produce the same allocation result.
- Scripts are distributed so the difference between TA workloads is at most one script.
- Stores:
  - `rule = RANDOM`
  - `seed = provided seed`
- Validates selected TAs belong to the exam's course.

## Seed Behaviour

- A seed is required for random allocation.
- The seed must be a finite integer.
- Missing or invalid seeds are rejected with a `400` error.

## Safety

- Only eligible scripts are allocated.
- Uses the allocation re-run contract from AE-082.
- Re-allocation is blocked once grading has started.
- Permission and ingestion approval gates are preserved.
