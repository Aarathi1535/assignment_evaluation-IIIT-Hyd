# AE-106A — Allocation Timing Metadata

### Objective

Add reliable timestamps to allocations so downstream dashboard features can calculate actual grading time and grading completion rate without using misleading proxies.

---

### What we're building

Two explicit lifecycle timestamps:

- `claimedAt`
- `completedAt`

---

### Done when

- `Allocation` stores `claimedAt`.

- `claimedAt` is set when a TA successfully claims an allocation.

- `Allocation` stores `completedAt`.

- `completedAt` is set when `markCompleted()` successfully transitions an allocation to `COMPLETED`.

- Existing allocation status transitions remain unchanged.

- Reassignment does not incorrectly overwrite `completedAt`.

- Timestamps represent the intended lifecycle events rather than generic document updates.

- Existing functionality remains compatible with allocations where these fields are not yet populated.

- Missing timestamps are not fabricated using `createdAt` or `updatedAt`.

- Tests verify the timestamp behavior.

---

### Timing semantics

```text
createdAt
    │
    │ queue wait
    ▼
claimedAt
    │
    │ actual grading time
    ▼
completedAt
```
