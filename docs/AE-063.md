# AE-063 — Re-split / Merge / Reorder Pages UI

## Objective

Provide an operator-facing UI to correct incorrect script/page grouping after
ingestion.

## Scope

- Display the persisted scripts and their ordered pages.
- Allow an authorized reviewer to move a page between scripts.
- Allow a reviewer to merge scripts.
- Allow a reviewer to split a script into corrected groups.
- Allow a reviewer to reorder pages within a script.
- Refresh the displayed state after a successful correction.
- Clearly indicate correction failures without losing the current review context.

## Source of Truth

`IngestionPage.answerScript` remains authoritative for page-to-script
membership.

The frontend must consume persisted script/page relationships and must not
recreate the splitting algorithm.

`AnswerScript.startPageNumber`, `endPageNumber`, and `pageCount` are derived
server-side and must not be independently maintained by the frontend.

## Authorization

- Require `EDIT_EXAM`.
- Restrict the UI to authorized exam/batch operators.
- Graders and students must not perform corrections.
- Reuse existing owner-scoped authorization.

## Acceptance Criteria

- Scripts and their pages are displayed using persisted relationships.
- A page can be moved from one script to another.
- Scripts can be merged.
- A script can be split into corrected groups.
- Pages can be reordered within a script.
- The UI sends corrections to the existing AE-064 backend endpoints.
- Successful corrections refresh the persisted script/page state.
- Page ordering is preserved after correction.
- Script range/count summaries displayed by the UI reflect backend state.
- Invalid corrections show a useful error.
- Concurrent/stale corrections are handled by the backend response.
- The UI does not implement its own splitting algorithm.
- Relevant tests, TypeScript, ESLint, and diff checks pass.

## Out of Scope

- Backend correction endpoints — **AE-064**.
- Manual student-ID assignment — **AE-062**.
- New splitting algorithms.
- OCR/QR changes.
- Duplicate/blank page detection — **AE-065**.
