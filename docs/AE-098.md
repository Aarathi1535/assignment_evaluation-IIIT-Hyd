# AE-098 — Professor Progress Aggregation

## Objective
Provide a professor-facing progress aggregation endpoint (`GET /api/exams/[id]/progress`) that reports grading progress per teaching assistant (TA) for a specific exam. Progress calculations are performed using a server-side MongoDB aggregation pipeline rather than loading documents into application memory.

## Implementation Details

### 1. Database Operations & Aggregation
Implemented in [`src/services/AllocationService.ts`](file:///c:/Users/AARATHISREE/Desktop/IIIT%20Hyd%20-%20Assignment%20Evaluation/Project%20Repo/assignment-evaluator/src/services/AllocationService.ts):
* **Method (`getProgress` / `getExamProgress`)**:
  Executes a MongoDB aggregation pipeline on the `allocations` collection:
  1. **`$match`**: Filters allocations strictly matching the given `exam` ID.
  2. **`$group`**: Groups by `ta` (`_id: '$ta'`), computing:
     * `total`: `$sum: 1` (total allocations assigned to that TA for the exam).
     * `graded`: Conditional sum counting allocations whose status is `AllocationStatus.COMPLETED`.
  3. **`$lookup`**: Joins with the `users` collection to retrieve the TA's name for professor-facing visibility.
  4. **`$unwind`**: Unwinds the TA user information.
  5. **`$project`**: Shapes the result objects containing `taId`, `name`, `graded`, and `total`.
* **Allocation Lifecyle & Transition**:
  * Allocation statuses follow the standard lifecycle (`PENDING` -> `IN_PROGRESS` -> `COMPLETED`).
  * `AllocationStatus.COMPLETED` is reached through `AllocationService.markCompleted()` (from AE-099), which will be called by the future Week-7 grading save flow.
* **Allocation Model Support**:
  * Seamlessly supports both whole-script allocations and question-wise allocations without requiring special-case counters.
* **Privacy & Security**:
  * Student identification, roll numbers, and answer script details are never projected or exposed in this endpoint. TA identities are intentionally visible as this is a professor-facing overview.

### 2. API Endpoint: `GET /api/exams/[id]/progress`
Created at [`src/app/api/exams/[id]/progress/route.ts`](file:///c:/Users/AARATHISREE/Desktop/IIIT%20Hyd%20-%20Assignment%20Evaluation/Project%20Repo/assignment-evaluator/src/app/api/exams/%5Bid%5D/progress/route.ts):
* **Authorization**:
  Enforces `Permission.ALLOCATE_SCRIPTS` via `requirePermission(Permission.ALLOCATE_SCRIPTS)` at the route level.
  * Authorized: `PROFESSOR`, `ADMIN`.
  * Unauthorized: `TA`, `STUDENT` (rejected with 403 Forbidden).
* **Validation**:
  Validates that `id` is a valid MongoDB ObjectId and verifies exam existence (404 if not found).
