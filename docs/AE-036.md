# AE-036 - Enroll Students to a Course/Exam

## Objective
Allow professors to attach student rosters to courses and exams.

## Acceptance Criteria

- Professors can enroll students into courses.
- Professors can enroll students into exams.
- Enrollment is owner-scoped.
- Atomic enrollment using `$addToSet`.
- RBAC enforced.
- Audit logging enabled.

## Validation

- Unauthorized users receive 403/404.
- Duplicate enrollments are idempotent.
- Cross-professor access is denied.
