# AE-065 — Duplicate / Blank Page Detection

## Objective

Detect suspicious pages during ingestion and flag them for operator review.

## Scope

- Detect near-blank pages.
- Detect likely duplicate pages.
- Flag suspicious pages without deleting or discarding them.
- Make detection results available to the operator workflow.

## Detection Mechanisms

### Near-blank Detection

Use the percentage of non-white pixels in the page image.

- Define and document an explicit threshold.
- Pages below the threshold are flagged as `near_blank`.
- The threshold may require tuning against real scanned answer sheets because
  scanner noise and page edges may not be pure white.

### Duplicate Detection

Use perceptual image hashing rather than exact byte hashing.

- Use pHash or dHash.
- Compare hashes using a documented Hamming-distance threshold.
- Detect duplicates within the same ingestion batch.
- Exact byte equality must not be the only duplicate mechanism because the
  same physical page may differ due to compression or scanner noise.

## Duplicate Scope

For v1, duplicate detection is limited to pages within the same batch.

Cross-batch and cross-exam duplicate detection are out of scope.

## Safety

- Detection only flags pages for review.
- No automatic deletion.
- Flagged pages remain available to operators.
- Normal pages should not be unnecessarily flagged.

## Acceptance Criteria

- Near-blank pages are detected using the documented non-white-pixel
  threshold.
- Duplicate pages are detected using the documented perceptual-hash method
  and Hamming-distance threshold.
- Duplicate comparison is limited to the current batch.
- Detection results are persisted or exposed through the existing ingestion
  data model/API.
- Flagged pages remain available for review.
- No page is automatically deleted because it was flagged.
- Tests cover positive and negative near-blank detection.
- Tests cover positive and negative duplicate detection.
- Relevant TypeScript, ESLint, and diff checks pass.

## Out of Scope

- Manual student-ID assignment — **AE-062**.
- Script remap/merge/split/reorder — **AE-063 / AE-064**.
- OCR/QR changes.
- Cross-batch duplicate detection.
- Cross-exam duplicate detection.
- Automatic deletion of flagged pages.
