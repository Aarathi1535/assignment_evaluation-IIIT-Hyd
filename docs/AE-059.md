# AE-059 — Batch Status View

## Objective

Provide visibility into ingestion processing for a submitted batch.

## Scope

- Show batch status.
- Show total, processed, and failed page counts.
- Show active script count when available.
- Show sanitized failure information.
- Show processing duration.
- Poll `GET /api/ingest/[id]` every 2–3 seconds while processing.
- Stop polling on terminal state.
- Clean up polling on unmount.
- Show useful feedback for long-running processing.

## Acceptance Criteria

- Processing status and page counts are visible.
- Script count is shown when available.
- Polling updates the UI while processing.
- Polling stops after completion/failure.
- Long-running processing shows elapsed-time information.
- Errors and unauthorized access are handled safely.

## Out of Scope

- Upload UI — **AE-058**
- Script/thumbnail APIs
- Split preview — **AE-060**
- Worker or splitting changes
