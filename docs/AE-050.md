# AE-050 — QR/Barcode Cover-Sheet Detection

## Objective

Automate the detection and extraction of student identifiers from QR codes and barcodes located on the cover sheet (page 1) of uploaded student submissions during ingestion.

## Scope

- Scan only page 1 (cover page) of each uploaded file.
- Decode QR/barcodes from the canonical normalized IngestionPage image, not the original upload.
- Use `@zxing/library` for decoding.
- Support both PDF and image inputs through the existing normalization pipeline.
- Persist on `IngestionPage`:
  - `isCoverPage` (boolean)
  - `candidateStudentId` (string | null)
  - `decodeOutcome` ('found' | 'not_found' | 'multiple' | null)
- Distinguish decode outcomes:
  - `found`: Exactly one candidate identifier was decoded.
  - `not_found`: No readable code was found on the cover page.
  - `multiple`: More than one distinct code was found on the cover page.
- Persist the candidate student identifier upon successful decode.
- Ensure unreadable/missing codes produce a controlled outcome and do NOT fail ingestion.
- Do not perform roster lookup (deferred to downstream workflow).
- Do not create or bind AnswerScript records.
- Do not implement manual ID queue handling (AE-053).
- Do not scan non-cover pages (`pageNumber > 1`).
- Preserve all existing ingestion behavior, idempotency, and error handling.

## Architecture

```
Uploaded File (PDF / Image)
           │
           ▼
PageRenderer (DefaultPdfRenderer / DefaultImageRenderer)
           │
           ▼
Canonical Normalized Page Image (RenderedPageImage)
           │
           ├──────────────────────────────┐
           │ (if pageNumber === 1)        │ (if pageNumber > 1)
           ▼                              ▼
CoverSheetDetector (@zxing/library)    Skip detection
           │                              │
           ▼                              ▼
isCoverPage: true                      isCoverPage: false
candidateStudentId: string | null      candidateStudentId: null
decodeOutcome: found|not_found|multiple decodeOutcome: null
           │                              │
           └──────────────┬───────────────┘
                          │
                          ▼
             Persist on IngestionPage
```

## Acceptance Criteria

- [x] Barcode/QR scanning is performed exclusively on `pageNumber === 1` of each uploaded file.
- [x] Detection uses the canonical normalized `IngestionPage` image buffer.
- [x] `@zxing/library` is utilized for decoding without introducing extraneous heavy dependencies.
- [x] Both PDF and standalone image submissions pass through cover-sheet detection.
- [x] `isCoverPage`, `candidateStudentId`, and `decodeOutcome` are persisted on `IngestionPage`.
- [x] `decodeOutcome` correctly distinguishes between `found`, `not_found`, and `multiple`.
- [x] Ingestion succeeds smoothly regardless of whether a code is found, missing, or corrupt.
- [x] Non-cover pages are not scanned and have `isCoverPage: false`.
- [x] Roster lookup and AnswerScript binding remain cleanly decoupled.
- [x] Unit and integration tests cover all specified scenarios.
