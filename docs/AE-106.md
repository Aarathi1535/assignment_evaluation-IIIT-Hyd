# AE-106 — Professor Dashboard: Per-TA Live Progress

### Objective

Build the professor-facing dashboard showing grading progress for each Teaching Assistant, using the existing progress APIs and SSE infrastructure.

---

### What we're building

At-a-glance per-TA grading status.

---

### Done when

- Professor/admin can view per-TA grading progress for an exam.

  Each TA displays `graded / total`.
  *Example:* `TA A — 45/60`

- Each TA has a visual progress bar.

- Progress percentage is calculated from the existing backend progress result.

- Dashboard consumes the existing progress endpoint: `GET /api/exams/[id]/progress`

- Dashboard consumes the existing SSE endpoint for live updates: `GET /api/exams/[id]/progress/stream`

- No duplicate grading/progress calculation is introduced in the frontend.

- Existing professor/admin authorization is preserved.

- No charting library is introduced for AE-106.

- Existing `live_updates_unavailable` SSE state can be surfaced by the dashboard where applicable.

---

### Architecture constraint

```text
AllocationService
      ↓
MongoDB Change Stream
      ↓
ProgressEventService
      ↓
SSE
      ↓
Professor Dashboard
```

The frontend must consume this existing chain rather than create another progress calculation or event mechanism.
