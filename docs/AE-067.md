# [AE-067] Contrast/brightness normalization

## Objective

Automatically improve readability of faint or low-contrast scanned pages and store the result as the page's derived enhanced image.

## Acceptance criteria

- [ ] Detect pages that are sufficiently faint or low-contrast to require enhancement.
- [ ] Apply brightness/contrast normalization only when enhancement is needed.
- [ ] Already-good scans remain substantially unchanged.
- [ ] The enhanced image is stored as the derived page asset.
- [ ] The original uploaded image remains immutable.
- [ ] The same input and parameters produce deterministic output.
- [ ] Enhancement processing failure does not prevent normal page ingestion.

## Validation

- [ ] Test faint/low-contrast fixtures and verify improved readability properties.
- [ ] Test normal scans and verify they remain within an acceptable similarity threshold to the original.
- [ ] Test high-contrast scans and verify they are not unnecessarily degraded.
- [ ] Verify the original source image remains unchanged.
- [ ] Verify the derived enhanced asset is generated successfully.
- [ ] Run `npx vitest run`.
- [ ] Run `npx tsc --noEmit`.
- [ ] Run `npm run lint`.
- [ ] Run `git diff --check`.

## Out of scope

- Manual image-editing controls.
- OCR or text reconstruction.
- Permanent modification of the original uploaded image.
- Student identification or manual tagging.
