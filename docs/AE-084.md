# AE-084: Question-Wise Allocation Strategy

## Overview

Implemented the `QUESTION` allocation strategy for assigning specific questions from each eligible answer script to selected teaching assistants.

## Implemented

- Added question-wise allocation through `AllocationService`.
- Questions are addressed by index from `1` to `exam.numberOfQuestions`.
- Validates that `numberOfQuestions` is an integer greater than or equal to `1`.
- Validates selected TAs belong to the exam's course.
- Distributes questions across TAs in a deterministic round-robin order.
- Supports more questions than TAs by assigning multiple questions to a TA.
- Creates allocations with:
  - `rule = QUESTION`
  - `question = question number`

## Safety

- Only eligible scripts are allocated.
- Uses the allocation re-run contract from AE-082.
- Prevents re-allocation once grading has started.
- Permission and ingestion approval gates are preserved.
- The allocation and grade models support multiple question records for the same answer script.
