# AE-089: Allocation Correctness Tests

## Overview

Added focused testing assertions and correctness verification suites for Teaching Assistant (TA) allocation algorithms. This verifies that answer script and question-wise allocations behave deterministically and avoid duplication conflicts or overlapping assignments.

## Verification Specifications

### 1. Seeded Random Allocation Completeness & Uniqueness
- Verified that under the `RANDOM` rule, every eligible answer script is allocated exactly once.
- Verified that there are no duplicate allocations of the same script to multiple TAs.
- Proven across multiple distinct seed values (e.g. `seed = 42`, `seed = 1337`, `seed = 2026`).

### 2. Cross-Rule Non-Overlap Constraints

#### EQUAL and RANDOM Rules (Whole-Script Allocations)
- Added checks asserting that no raw `answerScript` document appears more than once in the resulting set of allocations.
- Each eligible script is assigned to exactly one TA.

#### QUESTION Rule (Question-Wise Allocations)
- Added checks asserting that no unique `(answerScript, question)` pair appears more than once.
- Prevents the same question of an answer script from being assigned to multiple teaching assistants simultaneously.
