# AE-058 — Upload UI

## Objective

Provide a professor/admin UI to select an exam, upload answer-sheet files, and track upload and processing progress.

## Scope

- Owner-scoped exam selection.
- Drag-and-drop and file picker.
- Selected file list and validation.
- Real upload progress using `XMLHttpRequest`.
- Separate processing progress using `GET /api/ingest/[id]`.
- Handle server validation and upload errors.

### Client Limits

- Single file: 50 MB
- Files per batch: 20
- Total request: 200 MB
- PDF pages: 200

Client validation is UX only; the server remains authoritative.

## Acceptance Criteria

- Authorized professor/admin can select an exam and upload files.
- Upload progress is shown separately from processing progress.
- Processing status is polled after upload.
- Server errors are displayed clearly.
- Existing ingestion logic is not reimplemented.

## Out of Scope

- Batch status page — **AE-059**
- Split preview — **AE-060**
- New ingestion/splitting/identification logic
