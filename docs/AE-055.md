
# AE-055 — Fixed-Page Script Splitting

## Objective

Add an explicit fixed-pages-per-script splitting strategy for exams that do not use cover-page boundaries.

**Architecture update:** This ticket follows the revised architecture established by **#39, #40, #41, and #42**. `AnswerScript` is the script-level identity unit, while splitting determines page membership independently of student identity.

## Scope

- Add an explicit per-exam `FIXED_PAGE` splitting strategy.
- Add configurable `fixedPageCount`.
- Implement `FixedPageSplittingStrategy` using `PageSplittingStrategy`.
- Preserve page ordering and file boundaries.
- Never silently fall back to fixed-page splitting when cover/QR detection fails.
- Surface incomplete final groups for manual review.
- Preserve existing cover-page splitting behavior.

## Acceptance Criteria

- Fixed-page splitting is selected only when explicitly configured.
- Pages are grouped into consecutive groups of `N`.
- Invalid `fixedPageCount` is rejected.
- File boundaries are preserved.
- An incomplete final group is marked for manual review with `INCOMPLETE_SCRIPT`.
- Existing cover-boundary behavior remains unchanged.
- Relevant tests, TypeScript, ESLint, and diff checks pass.

## Out of Scope

- Page-to-AnswerScript persistence — **#45**.
- End-to-end integration testing — **#46**.
- Student identification or roster logic changes.
- OCR identification.

## Dependencies

**Depends on:** **#43 / AE-054** — `PageSplittingStrategy`.

**Enables:** **#45 / AE-056** — persistence of page-to-script relationships.
