# AE-082: Allocation Foundation and Rule Types

## Overview

Extended the existing allocation foundation to support multiple allocation strategies.

## Implemented

- Added allocation rules:
  - `EQUAL`
  - `QUESTION`
  - `RANDOM`
- Added optional allocation fields:
  - `rule`
  - `question`
  - `seed`
- Updated allocation indexing to support question-wise allocation.
- Updated grading storage to support question-wise grades.
- Prevented invalid mixing of whole-script and question-wise allocation/grading.
- Added allocation re-run handling:
  - Pending allocations can be replaced.
  - Re-allocation is blocked once grading has started.

## API and Safety

The existing allocation route was extended without removing:

- Permission validation
- Ingestion approval requirement
