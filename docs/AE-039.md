# AE-039 – Rubric Builder User Interface

## Objective

Implement a dynamic Rubric Builder interface that allows professors to create and manage grading rubrics through the web application.

The interface integrates with the rubric backend APIs while providing client-side validation and live score calculations.

---

## Functional Requirements

### Rubric Builder

The interface supports:

- Adding questions
- Removing questions
- Adding grading criteria (sub-parts)
- Removing grading criteria
- Editing question marks
- Editing criterion descriptions
- Editing criterion points

---

### Live Calculations

Automatically calculate:

- Total points for each question
- Overall rubric marks

Display validation when totals differ from the expected exam marks.

---

### Client-side Validation

Validate:

- Required fields
- Positive marks
- Positive criterion points
- Duplicate question numbers
- Criterion totals exceeding question maximum marks

Prevent invalid submissions.

---

### Backend Integration

Integrates with:

- POST /api/rubrics
- GET /api/rubrics
- GET /api/rubrics/[id]
- PUT /api/rubrics/[id]

Supports:

- Creating new rubrics
- Loading existing rubrics
- Updating existing rubrics

---

## Acceptance Criteria

- Professors can configure grading rubrics.
- Existing rubrics load correctly.
- Dynamic add/remove operations function correctly.
- Live totals update automatically.
- Validation prevents invalid submissions.
- Successfully saved rubrics persist after page refresh.

---

## Validation Performed

Verified through:

- Rubric Builder frontend tests
- Manual browser testing
- API integration testing

Quality gates:

- npm test
- npm run lint
- npx tsc --noEmit
- npm run build

---

## Design Notes

- Validation logic is extracted into reusable utility functions.
- Uses the existing application layout and component styling.
- Reuses existing API response patterns for consistency.
