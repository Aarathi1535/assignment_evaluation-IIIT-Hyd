# AE-061 — Week-3 Demo

## Objective

Demonstrate the complete ingestion workflow using a fresh batch.

## Demo Flow

Record:

1. Select exam.
2. Upload answer sheets.
3. Show upload progress.
4. Show processing status.
5. Show scripts and grouped pages.
6. Show identified student scripts.

## Required Failure Case

Demonstrate one unidentified script:

1. Script reaches `needs_manual_id`.
2. Operator identifies/tags the script.
3. Show that the script remains part of the batch.

## Acceptance Criteria

- Demo uses a fresh batch.
- Upload → processing → split → identification is demonstrated.
- One manual-identification failure case is shown.
- Demo video/evidence is attached to the issue or PR.

## Out of Scope

No new production functionality.
