# AE-108 — Professor Dashboard: TA Drill-Down

### Objective

Allow professors to click a TA and inspect their detailed grading workload.

---

### What we're building

TA-level detail.

---

### Done when

- Clicking a TA opens their detailed view.

- Display the TA's assigned scripts.

- Display grading status for each script.

- Display time-per-script information using `completedAt - claimedAt`.

- If the required timestamps are unavailable, do not display a misleading duration.

- Provide a clear way to return to the main dashboard.

### Anti-invention clause

> **Strict Semantic Boundary:** Do not use `updatedAt - createdAt` as time-per-script.

Time per script must be calculated only from `completedAt - claimedAt` when both timestamps are available.

AE-106A must provide `claimedAt` and `completedAt` before the time-per-script criterion is implemented.
