# AE-083: Equal-Split Allocation Strategy

## Overview

Implemented the `EQUAL` allocation strategy for distributing eligible answer scripts evenly across selected teaching assistants.

## Implemented

- Added `EQUAL` allocation through `AllocationService`.
- Validates selected TAs belong to the exam's course.
- Allocates only eligible scripts:
  - Active
  - Identified
  - Not marked for manual identification
- Distributes scripts so the difference between TA workloads is at most one script.
- Handles:
  - No eligible scripts
  - No selected TAs
  - One TA
  - More TAs than scripts
  - Remainder scripts

## Safety

- Uses the allocation re-run contract from AE-082.
- Existing pending allocations can be replaced.
- Re-allocation is blocked once grading has started.
- Permission and ingestion approval gates are preserved.
