# [AE-066] Auto-deskew & auto-rotate page images

## Objective

Automatically correct skewed and incorrectly oriented scanned pages during ingestion and store the corrected result as the page's derived enhanced image.

## Acceptance criteria

- [ ] Detect page skew up to ±10° and correct it to a residual skew of ≤0.5°.
- [ ] Detect and correct common 90°, 180°, and 270° orientation errors.
- [ ] Pages beyond the supported skew range are left unchanged and flagged for review rather than aggressively rotated.
- [ ] The corrected image is stored as a derived asset; the original uploaded image remains immutable.
- [ ] The same input produces the same correction result.
- [ ] Enhancement processing failure does not prevent normal page ingestion.
- [ ] Use the existing `@napi-rs/canvas` image-processing capability rather than introducing another native image dependency.

## Validation

- [ ] Test fixtures containing known skew angles within ±10°.
- [ ] Verify corrected fixtures have residual skew ≤0.5°.
- [ ] Test 90°, 180°, and 270° orientation cases.
- [ ] Test a page beyond the supported skew range and verify it is not incorrectly rotated.
- [ ] Verify the original source image is unchanged.
- [ ] Verify the derived enhanced asset is created successfully.
- [ ] Run `npx vitest run`.
- [ ] Run `npx tsc --noEmit`.
- [ ] Run `npm run lint`.
- [ ] Run `git diff --check`.

## Out of scope

- Manual rotation controls.
- OCR-based text reconstruction.
- Student identification or manual tagging.
- Permanent modification or replacement of the original uploaded image.
