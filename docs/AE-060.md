# AE-060 — Split Preview

## Objective

Provide an operator-facing preview of processed scripts, their pages, thumbnails, and detected student identity.

## Scope

- Display scripts as separate groups.
- Display ordered pages and thumbnails.
- Display page range/count.
- Display detected student identity when available.
- Clearly show unidentified/manual-review scripts.
- Use persisted script/page relationships.
- Do not recreate splitting in the frontend.

## Authorization

- Operator-facing only.
- Requires `EDIT_EXAM`.
- Graders must not access the preview.
- Backend authorization remains authoritative.

## Acceptance Criteria

- Authorized users can view a processed batch.
- Scripts and pages appear in the correct order.
- Pages appear under only one script.
- Thumbnails load through the authenticated API.
- Identified and unidentified scripts are clearly represented.
- Loading, empty, API-error, and thumbnail-error states are handled.

## Dependencies

- AE-056 — page-to-script persistence.
- AE-058 — upload UI.
- AE-059 — batch status.
- Ingestion preview backend endpoints.
